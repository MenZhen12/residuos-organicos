# Brota · Manejo de residuos orgánicos en el hogar

Proyecto del curso **PI-4803 Gestión de la Innovación** (Taller de Design Thinking) · **Grupo 3** · 2026.

**Equipo:** Gianmarco Forlani Villalta, Cesar Eduardo Gomez Medrano, Valeria Santos Mora, Keila Tamara Sibaja Mata y Kun Men Zheng Liang.

## Qué hay en este repositorio

| Archivo / carpeta | Contenido |
|---|---|
| `index.html` | Sitio web para el cliente final del producto (Brota: tritura, centrifuga y seca los restos de comida). |
| `proceso.html` | Recorrido del proyecto por las fases de Design Thinking: Empatizar, Definir e Idear, con el muro de evidencia y el banco de ideas. |
| `entregables/01-empatizar/` | Dossier, herramientas, análisis de sentimientos (notebook, datos y gráficos) y aplicativo del taller. |
| `entregables/02-definir/` | Taller Definir, Customer Journey y respaldo JSON. |
| `entregables/03-idear/` | Taller Idear, mapa mental, repositorio de herramientas y respaldos JSON. |

## Cómo verlo

- **En línea:** abra el enlace de GitHub Pages del repositorio (`https://<usuario>.github.io/<repositorio>/`).
- **En su computadora:** descargue el repositorio y abra `index.html` en Chrome o Edge.

## Notas

- La encuesta original tiene 32 respuestas anónimas (12 y 13 de octubre de 2026).
- "Brota" es un nombre provisional, y las cifras del producto son valores de referencia del concepto, no mediciones.
- No se incluyen las plantillas PDF del repositorio de herramientas del docente (Dinngo / designthinking.es), así que sus enlaces de descarga no funcionan desde este sitio.
